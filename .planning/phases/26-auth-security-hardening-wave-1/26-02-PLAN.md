## Goal

Giới hạn số lần thử login theo email (per-email throttle); khóa tạm tài khoản khi vượt ngưỡng; persist state trong PostgreSQL để survive Pi restart (thay vì in-memory).

---

## Implementation Steps

### Backend

1. **Schema: thêm cột vào `users` hoặc bảng `login_rate_limit`**

   Ưu tiên bảng riêng để không bloat `users`:
   ```sql
   CREATE TABLE login_rate_limit (
     email VARCHAR(255) PRIMARY KEY,
     attempt_count INT NOT NULL DEFAULT 0,
     first_attempt_at TIMESTAMPTZ,
     locked_until TIMESTAMPTZ,
     updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
   );
   ```

2. **`auth/login-rate-limit.service.ts`**
   - `checkAndIncrement(email: string): { allowed: boolean; lockedUntil?: Date }`
   - `reset(email: string): void` — gọi sau login success
   - `adminUnlock(email: string): void` — gọi từ admin API
   - Logic:
     - Nếu `locked_until > NOW()` → `allowed = false`
     - Increment `attempt_count`; nếu vượt `AUTH_MAX_LOGIN_ATTEMPTS` (default 5) → set `locked_until = NOW() + AUTH_LOCKOUT_DURATION_MINUTES`
     - Nếu `first_attempt_at + AUTH_RATE_WINDOW_MINUTES < NOW()` → reset counter

3. **ENV vars mới**
   ```
   AUTH_MAX_LOGIN_ATTEMPTS=5
   AUTH_RATE_WINDOW_MINUTES=15
   AUTH_LOCKOUT_DURATION_MINUTES=15
   ```

4. **Tích hợp vào `auth.service.ts`**
   - Gọi `loginRateLimitService.checkAndIncrement(email)` trước khi verify password
   - Nếu `!allowed` → throw `HttpException` với code `AUTH_ACCOUNT_LOCKED` và `lockedUntil`
   - Nếu login success → gọi `loginRateLimitService.reset(email)`

5. **Error response**
   ```json
   {
     "statusCode": 429,
     "error": "AUTH_ACCOUNT_LOCKED",
     "message": "Tài khoản tạm khóa do đăng nhập sai nhiều lần",
     "lockedUntil": "2026-05-27T04:00:00Z"
   }
   ```

6. **Cập nhật `docs/ERROR_HANDLING.md`** với `AUTH_ACCOUNT_LOCKED` error code

### PostgreSQL-backed (thay in-memory throttle hiện có)

- Prisma model `LoginRateLimit` với `@@map("login_rate_limit")`
- Dùng `upsert` với `conflict(email)` để atomic increment
- **Không** cần Redis; single-instance Pi dùng Postgres là đủ
