# Phase 26-03 Plan: Admin UI — Login Audit Log & Account Unlock + reCAPTCHA v3

**Phase:** 26 — Auth Security Hardening Wave 1
**Plan:** 26-03
**Issues:** #243, #244
**Status:** Not started

---

## Goal

1. Trang admin xem danh sách login audit events, filter theo email/status/thời gian; nút unlock tài khoản bị khóa.
2. Tích hợp Google reCAPTCHA v3 (score-based, ẩn) trên form login admin.

---

## Implementation Steps

### A. Admin Login Audit API (Backend)

1. **`GET /api/v1/admin/auth/audit-log`** — `@Roles('platform_super', 'shop_admin')`
   - Query params: `email`, `status` (`success` | `failed`), `from`, `to`, `page`, `limit`
   - Response: paginated `login_audit_log` rows
   - Dùng Prisma `findMany` với filter + `orderBy: { trace_id: 'desc' }` (UUIDv7 time-ordered)

2. **`POST /api/v1/admin/auth/unlock`** — `@Roles('platform_super', 'shop_admin')`
   - Body: `{ email: string }`
   - Gọi `loginRateLimitService.adminUnlock(email)`
   - Response: `204 No Content`

### B. Admin Login Audit UI (Frontend)

1. **Trang mới `/admin/security/audit-log`**
   - Table: `trace_id` (truncated), `email`, `status` (badge), `ip_address`, `user_agent`, timestamp (từ UUIDv7)
   - Filter bar: email search, status select, date range picker
   - Row action: "Mở khóa" nếu `status = failed` và tài khoản đang locked

2. **Tích hợp vào admin sidebar** dưới menu Security/Settings

### C. Google reCAPTCHA v3 (Backend)

1. **ENV vars**
   ```
   RECAPTCHA_SECRET_KEY=...
   RECAPTCHA_SCORE_THRESHOLD=0.5
   ```

2. **`auth/recaptcha.service.ts`**
   - `verify(token: string): Promise<boolean>`
   - Call `https://www.google.com/recaptcha/api/siteverify`
   - Return `score >= RECAPTCHA_SCORE_THRESHOLD`

3. **Tích hợp vào `auth.service.ts`**
   - `LoginDto` thêm optional `captchaToken?: string`
   - Nếu `RECAPTCHA_SECRET_KEY` configured: verify token; nếu fail → throw `CAPTCHA_FAILED` (403)
   - Nếu không configured: skip (dev mode)

### D. Google reCAPTCHA v3 (Frontend)

1. **ENV**: `VITE_RECAPTCHA_SITE_KEY=...`
2. Load `https://www.google.com/recaptcha/api.js` script khi vào `/admin/login`
3. Gọi `grecaptcha.execute(siteKey, { action: 'login' })` khi submit
4. Gửi token trong body `{ captchaToken }` cùng credentials
