## Goal

Gửi cảnh báo qua Telegram khi phát hiện tấn công brute-force, CAPTCHA fail liên tục, hoặc account lockout — với dedupe để tránh spam.

---

## Implementation Steps

### Backend

1. **`security/telegram-alert.service.ts`**
   - `sendAlert(type: AlertType, context: AlertContext): Promise<void>` — fire-and-forget
   - `AlertType`: `'account_locked' | 'captcha_failed_burst' | 'brute_force_detected'`
   - Dedupe: `Map<string, number>` (key = `${type}:${email/ip}`, value = `lastSentAt`); skip nếu `lastSentAt + ALERT_DEDUPE_TTL_MS > now`
   - Gửi qua Telegram Bot API: `POST https://api.telegram.org/bot{TOKEN}/sendMessage`

2. **ENV vars**
   ```
   TELEGRAM_BOT_TOKEN=
   TELEGRAM_CHAT_ID=
   SECURITY_ALERT_DEDUPE_TTL_MINUTES=5
   SECURITY_CAPTCHA_FAIL_THRESHOLD=3
   SECURITY_BRUTE_FORCE_THRESHOLD=10
   ```

3. **Tích hợp triggers**
   - `LoginRateLimitService.checkAndIncrement` → khi `locked_until` được set → `telegramAlertService.sendAlert('account_locked', { email })`
   - `RecaptchaService.verify` → track per-IP fail count → khi vượt threshold → `sendAlert('captcha_failed_burst', { ip })`
   - Tùy chọn: burst failed login từ cùng IP → `sendAlert('brute_force_detected', { ip })`

4. **Message format**
   ```
   🔒 [Diecast360] Account Locked
   Email: user@example.com
   Time: 2026-05-27T04:00:00Z
   IP: 1.2.3.4
   Reason: 5 failed attempts in 15 minutes
   ```

5. **Nếu Telegram không configured:** silent skip (không throw)
